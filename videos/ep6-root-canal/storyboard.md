# ep6 ปวดฟันจี๊ด! ต้องรักษารากฟันไหม?

สมจี๊ดปวดฟันจี๊ด หมอนวรัตน์ (การ์ตูนใบหน้าจริง ชุดสครับฟ้าอมเขียว) ตรวจในห้องทำฟัน เอกซเรย์ อธิบายแผน ขั้นตอนรักษาราก สิ่งที่ต้องทำต่อ และผลถ้าไม่รักษา

| ฉาก | ภาพ | เสียงพากย์ |
|---|---|---|
| 0 | ปก | - |
| 1 | ไอศกรีม จี๊ด! / ปวดตุบๆ ตอนตีสอง | โอ๊ย! สมจี๊ดกินไอศกรีมคำเดียว ปวดฟันจี๊ดขึ้นสมองเลยค่ะ ตกกลางคืน ยังปวดตุบๆ จนนอนไม่หลับ |
| 2 | ห้องตรวจ: หมอนวรัตน์เดินมา เปิดไฟส่องปาก | สมจี๊ดรีบมาที่คลินิกทันตกรรมบางปะอิน หมอนวรัตน์ชวนขึ้นเตียงทำฟัน แล้วเปิดไฟส่องปาก มาค่ะ หมอขอตรวจหน่อยนะคะ |
| 3 | ตรวจในปากด้วยกระจก+เครื่องมือ เจอฟันผุ เคาะเจ็บ | หมอใช้กระจกส่องปาก และเครื่องมือตรวจฟัน เจอฟันกรามซี่หนึ่ง ผุเป็นรูลึก พอเคาะเบาๆ ก็รู้สึกเจ็บค่ะ |
| 4 | เอกซเรย์: ผุถึงโพรงประสาท อักเสบปลายราก | หมอจึงถ่ายเอกซเรย์ดูข้างใน พบว่าฟันผุลึก ถึงโพรงประสาทฟัน และเริ่มมีการอักเสบที่ปลายรากค่ะ |
| 5 | ภาพตัดขวางฟัน เชื้อโรคบุก ประสาทอักเสบ | ข้างในฟันมีโพรงประสาท ที่มีเส้นประสาทและหลอดเลือดเล็กๆ เมื่อเชื้อโรคบุกเข้าไปถึง ประสาทฟันจะอักเสบ จึงปวดจี๊ด และปวดตุบๆ แบบนี้ค่ะ |
| 6 | ไวท์บอร์ดแผนการรักษา 3 ขั้น อาจนัดหลายครั้ง | หมอนวรัตน์บอกว่า ฟันซี่นี้ต้องรักษารากฟันค่ะ แล้วอธิบายแผนการรักษาให้ฟังทีละขั้น อาจต้องนัดหลายครั้ง ขึ้นอยู่กับอาการของฟันนะคะ |
| 7 | ขั้นที่ 1 ยาชา แผ่นยางกันน้ำลาย กรอเปิดทาง | ขั้นที่หนึ่ง หมอใส่ยาชาให้ก่อน แล้วใส่แผ่นยางกันน้ำลาย ให้ฟันสะอาดและแห้ง จากนั้นกำจัดเนื้อฟันที่ผุ และเปิดทางเข้าโพรงประสาทค่ะ |
| 8 | ขั้นที่ 2 ตะไบขยายคลองราก ล้างเชื้อ ใส่ยา อุดชั่วคราว | ขั้นที่สอง ทำความสะอาดคลองรากฟัน หมอใช้เครื่องมือเล็กๆ ขยายคลองราก แล้วล้างเชื้อโรคออก ใส่ยาฆ่าเชื้อในคลองราก แล้วปิดด้วยวัสดุอุดชั่วคราวค่ะ |
| 9 | ขั้นที่ 3 อุดคลองรากแน่น เชื้อเด้งกลับ | ขั้นที่สาม เมื่อคลองรากสะอาด และหายอักเสบแล้ว หมอจะอุดคลองรากให้แน่น ตลอดความยาวราก ปิดทางไม่ให้เชื้อโรคกลับเข้าไปได้อีกค่ะ |
| 10 | หลังรักษา 1-2: อุด/ครอบฟัน, เดือยฟัน+ครอบ | รักษารากเสร็จแล้ว ยังไม่จบนะคะ! หนึ่ง บูรณะฟันด้วยการอุด หรือครอบฟัน เพราะฟันที่รักษารากแล้วอาจเปราะ สอง ถ้าเนื้อฟันเหลือน้อย หมออาจใส่เดือยฟันก่อนทำครอบค่ะ |
| 11 | หลังรักษา 3-4: เลี่ยงของแข็ง, ติดตามผล, แปรง ไหมขัดฟัน ตรวจ 6 เดือน | สาม ระหว่างรอทำครอบ เลี่ยงเคี้ยวของแข็งด้วยฟันซี่นั้น สี่ มาตามนัด เพื่อถ่ายเอกซเรย์ติดตามผล และแปรงฟัน ใช้ไหมขัดฟัน ตรวจฟันทุกหกเดือนค่ะ |
| 12 | ถ้าไม่รักษา: ฟันตายสีคล้ำ ฝีปลายราก เหงือกบวม หายปวด≠หาย | แล้วถ้าไม่รักษารากฟันล่ะ? ประสาทฟันอาจตาย ฟันเปลี่ยนสีคล้ำ เชื้อโรคลามไปที่ปลายราก เกิดเป็นฝี เหงือกหรือหน้าบวมได้ บางครั้งหายปวด แต่ไม่ได้แปลว่าหายนะคะ |
| 13 | ปล่อยนาน: กระดูกถูกทำลาย ถอนฟัน ฟันข้างๆ ล้มเอียง | ถ้าปล่อยไว้นาน กระดูกรอบรากอาจถูกทำลาย จนเก็บฟันไว้ไม่ได้ ต้องถอนฟันค่ะ เมื่อฟันหายไป ฟันข้างๆ อาจล้มเอียง และเคี้ยวอาหารลำบาก |
| 14 | ตอนจบ: สมจี๊ดยิ้ม เคี้ยวสบาย อย่ารอนะคะ | การรักษารากฟัน ช่วยเก็บฟันธรรมชาติของเราไว้ได้ ถ้าปวดฟันจี๊ด หรือปวดตุบๆ ตอนกลางคืน อย่ารอนะคะ มาให้หมอตรวจได้เลยค่ะ |
| 15 | การ์ดคลินิก | นัดหมายคลินิกทันตกรรมบางปะอิน ทางไลน์ หรือโทรได้เลยค่ะ |
